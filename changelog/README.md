# Changelog

Each file documents a set of changes made on `dev` that are ready (or pending review) for merge to `main`.

## Naming convention
`YYYY-MM-DD-short-description.md`

## Template
```
## [vX.X.X] YYYY-MM-DD

### What changed
- ...

### Why
- ...

### Files touched
- ...

### Test
`python tests/test_YYYY-MM-DD_description.py`

### Status
- [ ] Tested locally
- [ ] Reviewed
- [ ] Ready to merge to main
```
