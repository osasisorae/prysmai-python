## [v0.9.0] 2026-04-09 — Dev branch features + README fix

### What changed
- **Response header parsing** — `PrysmClient` now surfaces `last_trace_id`, `last_threat_level`, `last_threat_score` from `X-Prysm-*` response headers.
- **REST fallback in `GovernanceSession`** — `_McpTransport` probes for MCP on first call and falls back to REST endpoints (`/governance/sessions`, `/governance/scan`) if MCP returns 404. Works against `prysmai-agent` today without a full MCP server.
- **`AsyncGovernanceSession`** — full async context manager with `check_behavior`, `scan_code`, `end`. Uses `httpx.AsyncClient` throughout.
- **Detector findings POST to backend** — `BaseDetector.configure_reporting()` called automatically when a detector is attached to a session. Detections POST to `/threat-events` best-effort.
- **`prysm_context.from_headers()`** — downstream services can receive and restore context propagated via `X-Prysm-*` headers.
- **Version bumped to 0.9.0** — `pyproject.toml`.
- **README local dev URL fixed** — `localhost:3000/api/v1` → `localhost:8000/v1` and `localhost:3000/api/mcp` → `localhost:8000/mcp` to match the current `prysmai-agent` FastAPI backend.

### Why
- All features were done on dev but blocked from merging due to stale README URLs pointing at the deprecated TypeScript backend.
